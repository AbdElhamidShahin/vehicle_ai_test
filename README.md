# Vehicle AI Test

Flutter Android prototype for testing voice-based vehicle data extraction.

## Current prototype
- Arabic RTL UI
- Microphone permission
- Record/stop audio
- Temporary audio file
- HTTP upload to FastAPI
- Result screen and test history
- Audio is deleted after a successful backend response

## Run
```powershell
flutter pub get
flutter run
```
